# Rubric: is this reproduction package ready to post?

## Checks

| Check                   | Evidence                                                                                                                                          | Pass condition                                                                                                                                                                                                                                                                              | Weight   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| environment             | The environment record in the repro report, read against the issue context and repo-facts block.                                                  | The report records the relevant environment details needed to interpret the reproduction. If the issue states a specific environment target, any meaningful difference from that target is explicitly identified.                                                                           | required |
| followable-reproduction | The reproduction steps and setup instructions in the repro report.                                                                                | A stranger can follow the stated setup and steps from the starting state to the reported outcome without needing unstated actions or assumptions.                                                                                                                                           | required |
| issue-behavior          | The artifacts in the repro report, such as output excerpts, logs, screenshots, or test results, read against the behavior described by the issue. | The artifacts demonstrate the issue's described behavior, or provide sufficient evidence for an honest cannot-reproduce conclusion. Evidence of only an adjacent behavior does not pass.                                                                                                    | required |
| honest-conclusion       | The repro report's conclusion compared with its environment, steps, and artifacts.                                                                | The conclusion says only what the evidence establishes. A cannot-reproduce conclusion passes when the investigation and evidence support it; a reproduction claim does not pass when its evidence does not establish the claimed behavior.                                                  | required |
| repository-conventions  | The claim and repro comments, issue context, and repo-facts block, including any contribution or AI-disclosure requirements.                      | The comments follow the repository's stated conventions, identify the student's own work, and satisfy each applicable contribution and disclosure requirement. When the repository requires AI-use disclosure, the comments explicitly disclose the required tool and extent of assistance. | required |

## Verdict rule

Accept if every required check passes. Preferred checks never change the
verdict. An unclear required check counts as a fail. Otherwise, reject.
